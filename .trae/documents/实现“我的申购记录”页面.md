# 实现“我的申购记录”页面

## 1. 创建新页面

* **创建** **`MySubscriptionRecordsScreen.tsx`**：参照 `SubscriptionRedemptionRecordsScreen.tsx` 结构

* **页面布局**：

  * 顶部导航栏，包含返回按钮、标题和图标

  * 四个功能按钮：申购申请、赎回申请、申赎记录、合同签订

  * “我的申购记录”完整列表

## 2. 页面功能

* **数据加载**：只加载申购类型的记录

* **记录展示**：格式化显示每条申购记录，包含第一行：基金名称、基金代码，第二行：类型、金额，第三行：日期和状态

* **功能按钮**：点击跳转到对应页面

* **下拉刷新**：支持数据刷新

* **状态管理**：处理加载、空状态和错误状态

## 3. 导航集成

* **更新** **`App.tsx`**：

  * 添加 `showMySubscriptionRecords` 状态

  * 添加 `setShowMySubscriptionRecords` 状态更新函数

  * 添加新页面的显示逻辑

  * 更新 `TradesScreen` 的导航回调

* **更新** **`TradesScreen.tsx`**：

  * 修改“我的申购记录”板块的“更多>>”按钮，使用新的导航回调

## 4. 数据类型和样式

* **复用现有类型定义**：`SubscriptionRedemptionRecord`

* **参照现有样式**：使用 `SubscriptionRedemptionRecordsScreen` 的样式设计

* **支持中英文切换**：添加语言翻译支持

## 5. 实现步骤

1. 创建 `MySubscriptionRecordsScreen.tsx`
2. 更新 `App.tsx` 状态和导航
3. 更新 `TradesScreen.tsx` 导航链接
4. 测试页面功能和导航

## 6. 预期效果

* 点击交易页面“我的申购记录”板块的“更多>>”链接，跳转到新的申购记录页面

* 新页面显示四个功能按钮和完整的申购记录列表

* 页面支持下拉刷新和状态处理

* 功能按钮可跳转到对应页面
