
# Aurora Capital 项目全面梳理与完善计划

## 一、项目整体架构分析

### 1.1 项目结构
- **apps/admin/**: 管理后台 (React + Ant Design + Vite)
- **apps/mobile/**: 移动应用 (React Native + Expo)
- **apps/web/**: 用户网站 (Next.js + Mantine + Tailwind CSS)
- **services/financial-data-scraper/**: 金融数据抓取服务
- **supabase/**: Supabase配置和数据库迁移
- **packages/**: 共享包 (types, utils)
- **functions/**: 数据库函数

### 1.2 技术栈
- **前端框架**: React 18, Next.js 14, React Native
- **UI组件库**: Ant Design 5, Mantine, Tailwind CSS
- **后端/数据库**: Supabase
- **构建工具**: Vite, Expo, Next.js
- **状态管理**: React Hooks + Context API
