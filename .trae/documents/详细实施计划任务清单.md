## 关键技术要点

### 1. 数据获取和状态管理
- 使用Supabase客户端进行数据获取
- 使用React hooks管理组件状态
- 合理使用Context API进行全局状态管理

### 2. UI组件库
- Web端：使用Tailwind CSS + Mantine UI
- Mobile端：使用React Native原生组件
- Admin端：使用Ant Design + Refine

### 3. 数据可视化
- 使用Recharts进行图表展示
- 确保图表在不同屏幕尺寸上的适配

### 4. 认证和权限
- 使用Supabase Auth进行用户认证
- 确保RLS策略正确配置
- 确保不同角色用户看到相应的功能和数据

### 5. 文件上传
- 使用Supabase Storage进行文件存储
- 实现文件上传进度显示
- 添加文件类型和大小限制

## 实施建议

1. **优先顺序**：按照阶段一到阶段六的顺序进行，确保核心功能优先完善
2. **参考实现**：充分参考Mobile和Admin端的现有功能，确保一致性
3. **测试驱动**：每完成一个功能模块，立即进行测试
4. **代码复用**：尽可能复用现有的组件和工具函数
5. **用户体验**：始终关注用户体验，保持界面简洁直观
