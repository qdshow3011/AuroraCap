# 修复申购/赎回/入金/出金消息中无法读取用户姓名的问题

## 问题分析

在生成基金交易消息时，无法读取登录用户姓名的主要原因可能有：

1. **RedemptionApplicationScreen 中可能传递 undefined userId**：
   - 调用 `generateFundTransactionMessage` 时使用了 `userInfo?.id`，没有提供默认值
   - 当 `userInfo` 为 null 或 undefined 时，userId 会是 undefined

2. **数据库查询可能失败**：
   - Supabase 客户端问题
   - RLS 策略限制
   - 用户 ID 无效
   - 网络问题
   - 字段名不匹配

3. **查询语句可能有问题**：
   - 可能数据库中存储用户名的字段名不是 `name` 或 `nickname`

## 修复方案

### 1. 修复 RedemptionApplicationScreen 中的 undefined userId

在 RedemptionApplicationScreen.tsx 中，为 userId 添加默认值：

```typescript
await messageGenerator.generateFundTransactionMessage(
  userInfo?.id || '',
  userInfo?.nickname || userInfo?.name || '用户',
  '赎回'
);
```

### 2. 优化消息生成器中的用户姓名获取逻辑

修改 `generateFundTransactionMessage` 函数，添加详细的错误日志和更可靠的用户名获取逻辑：

1. 添加详细的错误日志，便于调试
2. 确保 userId 有效再进行数据库查询
3. 优化用户名获取优先级
4. 确保返回可靠的用户名

### 3. 检查数据库表结构

确认 users 表中存储用户名的字段名是否为 `name` 和 `nickname`，如果不是则需要修改查询语句。

### 4. 优化调用参数传递

确保所有调用 `generateFundTransactionMessage` 的地方都正确传递了 userId 和 userName 参数：

- 确保 `userInfo` 不为 null 或 undefined
- 为 userId 提供默认值
- 为 userName 提供合理的默认值

## 修复后的代码示例

### 1. 修复 RedemptionApplicationScreen

```typescript
// 生成赎回消息通知
await messageGenerator.generateFundTransactionMessage(
  userInfo?.id || '',
  userInfo?.nickname || userInfo?.name || '用户',
  '赎回'
);
```

### 2. 优化消息生成器

```typescript
// 生成基金交易申请消息
async generateFundTransactionMessage(userId: string, userName: string, transactionType: '申购' | '赎回' | '入金' | '出金') {
  try {
    // 直接从数据库查询用户的详细信息，确保获取到正确的用户名
    let actualUserName = userName || '用户';
    
    console.log('Generating transaction message for user:', {
      userId,
      providedUserName: userName
    });
    
    // 只有当 userId 有效时才进行数据库查询
    if (userId) {
      const { data: userData, error: userError } = await supabase
        .from('users')
        .select('name, nickname')
        .eq('id', userId)
        .single();
    
      if (userError) {
        console.error('Failed to fetch user data:', userError);
        // 查询失败时，使用传入的 userName 或者默认值
        actualUserName = userName || '用户';
      } else if (userData) {
        console.log('Fetched user data:', userData);
        // 优先使用数据库中的实际姓名，其次使用传入的userName，最后使用默认值
        actualUserName = userData.name || userData.nickname || userName || '用户';
      } else {
        console.warn('No user data found for id:', userId);
        // 用户不存在时，使用传入的 userName 或者默认值
        actualUserName = userName || '用户';
      }
    } else {
      console.warn('Invalid userId provided:', userId);
      // userId 无效时，使用传入的 userName 或者默认值
      actualUserName = userName || '用户';
    }
    
    console.log('Final actualUserName:', actualUserName);
    
    const userContent = `${actualUserName},你的${transactionType}申请已经提交成功，我们正依据约定努力为您办理中，谢谢！`;
    const staffContent = `${actualUserName}的${transactionType}申请已经提交成功，请依据约定努力为您办理中，谢谢！`;
    
    // 后续消息生成逻辑...
  } catch (error) {
    console.error('Failed to generate fund transaction message:', error);
  }
}
```
