# Web首页完善和注册登录机制修改计划

## 一、首页完善计划

### 1. 首页结构调整
- 保留现有设计风格，但增加实际基金信息和功能模块
- 调整饥饿营销策略，从神秘感转向实际价值展示
- 增加基金产品展示、投资功能入口等实际内容

### 2. 基金信息展示模块
- **热门基金推荐**：展示3-5只热门基金，包含名称、最新净值、涨跌幅等信息
- **基金分类导航**：按类型（股票型、债券型、混合型等）展示基金
- **市场概览**：展示主要指数（沪深300、上证指数等）实时数据
- **投资策略介绍**：简要介绍AI投资策略

### 3. 功能模块添加
- **快速交易入口**：直接进入申购赎回页面
- **资产查询入口**：登录用户可直接查看资产
- **新闻资讯**：展示最新财经新闻和市场动态
- **投资组合分析**：提供投资组合分析工具入口

### 4. 数据可视化
- 添加基金净值走势图
- 添加资产配置饼图
- 添加市场趋势图表

## 二、注册登录机制修改计划

### 1. 登录机制完善
- 支持身份证号/护照号码/手机号码登录
- 优化登录表单设计
- 增加忘记密码功能
- 优化登录错误提示

### 2. 注册机制完善
- 调整注册表单字段，匹配mobile端：
  - 姓名
  - 身份证号/护照号码
  - 手机号码
  - 密码
  - 邀请码（必填）
- 增加表单验证
- 优化注册流程
- 增加注册成功反馈

### 3. 认证API调整
- 统一使用mobile端的认证API（loginUser, registerUser）
- 调整API调用逻辑
- 处理API返回结果

### 4. 用户状态管理
- 优化用户状态管理
- 完善登录状态持久化
- 优化权限控制

## 三、技术实现要点

1. **前端框架**：Next.js 14 + React 18 + TypeScript
2. **UI组件**：TailwindCSS + 自定义组件
3. **数据可视化**：Recharts
4. **状态管理**：React Hooks + Context API
5. **API集成**：使用mobile端的认证API
6. **表单处理**：React Hook Form
7. **验证机制**：Zod schema验证

1. **首页设计调整**：修改首页结构，添加基金信息模块
