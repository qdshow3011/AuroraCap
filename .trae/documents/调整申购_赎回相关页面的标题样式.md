## 调整申购/赎回相关页面的标题样式

### 目标
将申购申请、赎回申请和申购/赎回记录页面的标题样式调整为与出金申请页面一致，右侧放置搜索图标和客服图标。

### 参考样式
以出金申请页面(WithdrawalApplicationScreen)的标题样式为参考，其特点：
- 左侧：返回按钮
- 中间：标题文本
- 右侧：搜索图标和客服图标

### 修改页面
1. **SubscriptionApplicationScreen.tsx** (申购申请页面)
2. **RedemptionApplicationScreen.tsx** (赎回申请页面)
3. **SubscriptionRedemptionRecordsScreen.tsx** (申购/赎回记录页面)

### 每个页面的修改内容

#### 1. 修改标题结构
将当前的header结构替换为：
```tsx
<View style={styles.header}>
  <View style={styles.headerLeft}>
    <TouchableOpacity style={styles.backButton} onPress={onClose}>
      <Text style={styles.backButtonText}>←</Text>
    </TouchableOpacity>
    <Text style={styles.title}>{t.title}</Text>
  </View>
  <View style={styles.headerIcons}>
    <TouchableOpacity style={styles.iconButton} onPress={() => console.log('搜索')}>
      <Text style={styles.icon}>🔍</Text>
    </TouchableOpacity>
    <TouchableOpacity style={styles.iconButton} onPress={() => console.log('客服')}>
      <Text style={styles.icon}>🎧</Text>
    </TouchableOpacity>
  </View>
</View>
```

  fontSize: 24,

},

  color: '#333',

},

},

#### 3. 调整现有样式
- 移除不需要的样式（如headerRight, placeholder等）
- 确保标题文本居中显示
- 调整padding值以匹配出金申请页面

### 修改步骤
1. 依次修改每个页面的标题结构
2. 更新每个页面的样式定义
3. 测试修改后的页面效果
4. 确保所有页面的标题样式一致

### 预期效果
所有四个页面（出金申请、申购申请、赎回申请、申购/赎回记录）的标题样式统一，右侧均显示搜索图标和客服图标。
