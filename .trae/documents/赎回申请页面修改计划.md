# 赎回申请页面修改计划

## 1. 增加可用份额字段

### 1.1 修改Position接口

* 在Position接口中增加`available_shares`字段，用于记录可用份额

* 更新数据类型定义，确保类型安全

### 1.2 更新数据库查询

* 在loadPositions函数中，确保从positions表获取available\_shares字段

* 如果数据库中还没有该字段，增加该字段，使用默认值（与shares相同）

### 1.3 修改产品信息展示

* 在renderProductInfo函数中，显示shares的同时显示available\_shares

* 更新UI显示，确保用户看到份额和可用份额

## 2. 修改赎回份额选项按钮

### 2.1 替换全部赎回按钮

* 删除当前的单一"全部赎回"按钮

* 添加多个选项按钮：全部、1/2、1/3、1/4、1/5

### 2.2 实现份额计算逻辑

* 创建handleRedemptionRatio函数，根据选择的比例计算赎回份额

* 点击不同选项时，自动计算并填充赎回份额文本框

* 确保计算结果保留合理的小数位数（小数点后2位）

### 2.3 更新UI样式

* 设计新的按钮样式，确保多个选项按钮美观排列

* 添加适当的间距和选中状态

## 3. 提交后更新可用份额

### 3.1 修改handleSubmit函数

* 在插入赎回记录后，添加更新positions表的逻辑

* 计算新的可用份额：当前可用份额 - 赎回份额

* 执行数据库更新操作

### 3.2 确保数据一致性

* 添加事务处理或错误处理，确保数据更新的一致性

* 如果更新失败，提供适当的错误提示

## 4. 更新语言翻译

* 在语言包中添加新的赎回比例选项文本

* 确保多语言支持

## 5. 测试修改

* 测试份额计算功能

* 测试可用份额更新逻辑

* 测试UI显示效果

### 预期效果

1. 基金产品信息中显示可用份额
2. 赎回份额选项包括：全部、1/2、1/3、1/4、1/5
3. 点击不同选项自动计算并填充赎回份额
4. 提交赎回申请后，可用份额相应减少
5. 保持良好的用户体验和UI设计
