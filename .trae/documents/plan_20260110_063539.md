# 客服管理功能实现计划

## 1. 功能需求分析

### 1.1 核心功能

* 在admin用户中心增加"客服管理"菜单

* 实现后台设置每个服务员（客服）管理对应客户功能

* 管理客服与用户对话的内容

### 1.2 数据结构

* **users表**：存储所有用户，包括admin、waiter（服务员）、customer（客户）等角色

* **chat\_sessions表**：存储聊天会话，关联user\_id（客户）和agent\_id（服务员）

* **messages表**：存储聊天消息

* **media\_files表**：存储媒体文件

## 2. 实现方案

### 2.1 导航菜单配置

* 在`navigation.tsx`中的`user-center`下添加"客服管理"菜单

* 配置路径：`/user-center/customer-service`

* 组件：`customer-service-management.tsx`

### 2.2 页面设计与实现

#### 2.2.1 客服管理主页面

* **服务员列表**：显示所有waiter角色的用户

* **客户分配功能**：

  * 选择服务员

  * 选择客户进行分配

  * 显示已分配客户列表

  * 支持取消分配

* **聊天会话管理**：

  * 显示服务员与客户的聊天会话

  * 支持查看聊天详情

  * 支持按状态筛选会话

  * 支持搜索功能

#### 2.2.2 聊天详情页面

* 显示聊天会话的所有消息

* 按时间顺序展示消息

* 支持不同类型消息的展示（文本、语音、图片、文件）

* 显示发送者信息和时间

### 2.3 数据库设计

* **现有表利用**：

  * 使用`users`表存储服务员和客户信息

  * 使用`chat_sessions`表关联服务员和客户

  * 使用`messages`表存储聊天内容

* **可能需要的新增关系**：

  * 如果需要长期绑定服务员与客户，考虑创建`customer_agent_relationships`表

  * 包含字段：id、customer\_id、agent\_id、created\_at、updated\_at

### 2.4 核心功能实现

#### 2.4.1 获取服务员列表

```typescript
const { data: waiters, error: waitersError } = await supabaseClient
  .from('users')
  .select('id, name, email, phone')
  .eq('role', 'waiter')
  .eq('status', 'active')
```

#### 2.4.2 获取客户列表

```typescript
const { data: customers, error: customersError } = await supabaseClient
  .from('users')
  .select('id, name, email, phone')
  .eq('role', 'customer')
  .eq('status', 'active')
```

#### 2.4.3 获取服务员已分配的客户

```typescript
const { data: relationships, error: relationshipsError } = await supabaseClient
  .from('chat_sessions')
  .select('user_id, users!user_id_fkey(name, email, phone)')
  .eq('agent_id', waiterId)
  .eq('status', 'active')
  .group('user_id')
```

#### 2.4.4 获取聊天会话列表

```typescript
const { data: sessions, error: sessionsError } = await supabaseClient
  .from('chat_sessions')
  .select('id, user_id, agent_id, status, last_message_at, users!user_id_fkey(name, email), users!agent_id_fkey(name, email)')
  .order('last_message_at', { ascending: false })
```

#### 2.4.5 获取聊天消息

```typescript
const { data: messages, error: messagesError } = await supabaseClient
  .from('messages')
  .select('id, sender_id, sender_type, message_type, content, media_id, created_at, media_files(file_name, file_url, file_type)')
  .eq('chat_session_id', sessionId)
  .order('created_at', { ascending: true })
```

## 6. 风险与注意事项

1. **数据一致性**：确保服务员与客户的分配关系在聊天会话中正确体现
2. **性能优化**：对聊天消息进行分页加载，避免一次性加载大量数据
3. **权限控制**：确保只有admin角色可以访问客服管理功能
4. **用户体验**：提供清晰的操作反馈和错误提示
