# 服务员客户管理功能增强计划

## 1. 功能需求分析

### 1.1 核心功能

* 在服务员管理页面展示每个服务员名下管理的客户数量

* 点击客户名称或管理客户按钮，显示该服务员管理的客户列表

* 点击客户名字，进入该服务员与该客户的聊天会话管理

* 优化聊天会话管理，支持按服务员和客户进行筛选

### 1.2 数据结构

* **users表**：存储所有用户，包括服务员和客户

* **chat\_sessions表**：存储聊天会话，关联服务员和客户

## 2. 实现方案

### 2.1 扩展服务员类型

* 在Waiter接口中添加customers属性，用于存储该服务员管理的客户列表

* 在fetchWaiters函数中，同时获取每个服务员管理的客户列表

### 2.2 增强服务员管理页面

* **添加管理客户列**：

  * 显示每个服务员管理的客户数量

  * 添加点击事件，显示客户列表

  * 使用Tag或Badge组件显示客户数量

* **客户列表弹窗**：

  * 显示该服务员管理的所有客户

  * 支持点击客户名称进入聊天会话

  * 支持搜索和筛选

### 2.3 优化聊天会话管理

* **添加筛选功能**：

  * 按服务员筛选会话

  * 按客户筛选会话

  * 支持组合筛选

* **会话详情页面**：

  * 显示该服务员与该客户的所有聊天消息

  * 支持不同类型消息的展示

  * 显示消息发送者和时间

### 4.1 数据获取优化

* 使用Supabase的left join查询，一次获取服务员和关联的客户

* 优化查询性能，避免N+1查询问题

### 4.2 组件设计

* 复用现有的Table组件，减少代码重复

* 使用Select组件实现筛选功能

### 4.3 状态管理

* 使用useEffect监听筛选条件变化，更新会话列表

## 6. 实现代码结构

```typescript
// 扩展类型定义
interface Waiter {
  id: string;
  name: string;
  email: string;
  phone: string;
  customers: Customer[];
}

// 数据获取
const fetchWaitersWithCustomers = async () => {
  // 使用left join查询获取服务员及其管理的客户
  const { data: waiters, error } = await supabaseClient
    .from('users')
    .select(`
      id, name, email, phone,
      // 获取该服务员管理的客户
      chat_sessions (
        user_id,
        users!user_id_fkey (id, name, email, phone)
      )
    `)
    .eq('role', 'waiter')
    .eq('status', 'active');
  
  // 格式化数据
  const formattedWaiters = waiters.map(waiter => ({
    ...waiter,
    customers: waiter.chat_sessions?.map(session => session.users) || []
  }));
  
  return formattedWaiters;
};

// 客户列表弹窗组件
const CustomerListModal = ({ waiter, visible, onCancel, onCustomerClick }) => {
  return (
    <Modal
      title={`${waiter.name} 管理的客户`}
      visible={visible}
      onCancel={onCancel}
      footer={null}
    >
      <Table
        columns={[
          {
            title: '客户名称',
            dataIndex: 'name',
            render: (text, record) => (
              <a onClick={() => onCustomerClick(record)}>{text}</a>
            )
          },
          // 其他列...
        ]}
        dataSource={waiter.customers}
        rowKey="id"
      />
    </Modal>
  );
};
```

## 7. 风险与注意事项

1. **性能优化**：确保数据获取逻辑高效，避免N+1查询问题
2. **UI体验**：确保弹窗和页面切换流畅，提供良好的用户体验
3. **权限控制**：确保只有授权用户可以查看和管理客户
4. **数据一致性**：确保服务员管理的客户列表与实际聊天会话一致
