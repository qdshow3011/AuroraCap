# 完善Web功能实现计划

## 一、功能梳理与对比

### Mobile端现有功能
1. **账户管理**：账户信息查看与编辑、实名认证
2. **资产状态**：总资产概览、资金明细、交易记录
3. **产品管理**：产品列表、产品详情
4. **交易功能**：申购申请、赎回申请
5. **资金管理**：入金服务、出金申请
6. **合同管理**：合同详情、合同签署
7. **客服系统**：在线客服聊天
8. **消息中心**：消息列表、消息详情
9. **个人中心**：个人资料编辑、头像上传

### Web端当前功能
1. **基础登录**：用户登录、观察员登录
2. **基金列表**：产品展示
3. **用户中心**：基础资产展示、交易记录、持仓信息
4. **简单个人设置**

## 二、Web功能完善计划

### 1. 账户信息管理模块
- **页面**：`/user/profile`
- **功能**：
  - 账户信息展示与编辑
  - 实名认证功能
  - 头像上传与编辑
- **UI优化**：现代化卡片设计、响应式布局

### 2. 资产状态详情模块
- **页面**：`/user/assets`
- **功能**：
  - 总资产饼图展示
  - 资金明细（可用余额、总入金、总出金、在途资金）
  - 入金出金记录列表
- **UI优化**：数据可视化图表、实时数据更新

### 3. 产品详情模块
- **页面**：`/funds/[fundId]`
- **功能**：
  - 产品详细信息展示
  - 历史净值走势图表
  - 申购赎回入口
- **UI优化**：交互式图表、清晰的产品信息布局

### 4. 申购赎回功能
- **页面**：
  - `/funds/[fundId]/subscribe`
  - `/funds/[fundId]/redeem`
- **功能**：
  - 申购金额输入与确认
  - 赎回份额输入与确认
  - 交易成功反馈
- **UI优化**：步骤式引导、实时金额计算

### 5. 入金出金功能
- **页面**：
  - `/user/deposit`
  - `/user/withdraw`
- **功能**：
  - 入金申请流程
  - 出金申请流程
  - 资金记录查询
- **UI优化**：简洁的表单设计、状态清晰的记录列表

### 6. 合同管理模块
- **页面**：
  - `/user/contracts`
  - `/user/contracts/[contractId]`
- **功能**：
  - 合同列表展示
  - 合同详情查看
  - 电子合同签署
- **UI优化**：分类合同列表、在线合同阅读器

### 7. 客服系统模块
- **页面**：`/user/service`
- **功能**：
  - 在线客服聊天
  - 聊天记录查看
- **UI优化**：现代化聊天界面、消息状态指示

### 8. 消息中心模块
- **页面**：
  - `/user/messages`
  - `/user/messages/[messageId]`
- **功能**：
  - 消息列表展示
  - 消息详情查看
  - 消息已读状态更新
- **UI优化**：清晰的消息分类、未读消息提示

### 9. 整体UI优化
- **导航栏**：统一导航结构、响应式设计
- **布局**：现代化卡片式布局、合理的间距与留白
- **颜色**：统一配色方案、视觉层次感
- **交互**：流畅的动画效果、清晰的反馈提示
- **响应式**：适配不同屏幕尺寸

## 三、技术实现要点

1. **前端框架**：Next.js 14 + React 18 + TypeScript
2. **UI组件库**：TailwindCSS + Mantine UI
3. **数据可视化**：Recharts
4. **状态管理**：React Hooks + Context API
5. **API集成**：Supabase Auth + REST API
6. **文件上传**：Supabase Storage
7. **实时通信**：Supabase Realtime
