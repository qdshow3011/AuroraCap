# 账号信息页面账户类型选择框调整计划

## 问题分析

当前账户类型选择框的问题：

1. **布局问题**：选择框中的文字和箭头紧邻，不够美观
2. **位置问题**：选择框整体需要调整到区块右侧，与其他输入字段保持一致的布局

## 修复方案

### 1. 调整选择框容器样式

**修改** **`AccountInfoScreen.tsx`** 中的样式定义：

* 调整 `moduleSelect` 样式，确保选择框位于右侧

* 增加 `selectContainer` 中文字和箭头之间的间距

* 确保选择框与其他输入字段保持一致的外观

### 2. 优化选择框的交互体验

* 确保选择框点击区域足够大，便于用户操作

* 保持与页面整体风格的一致性

### 3. 验证账户类型修改功能

* 确认账户类型的 `editable` 属性已设为 `true`

* 确认修改后的账户类型能正确保存到数据库

## 修复后的代码示例

### 调整样式定义

```typescript
// 修改样式定义
moduleSelect: {
  paddingVertical: 8,
  minWidth: 120, // 确保选择框有足够的宽度
  alignItems: 'flex-end', // 确保内容靠右对齐
},
selectContainer: {
  flexDirection: 'row',
  alignItems: 'center',
  justifyContent: 'flex-end', // 确保整个容器内容靠右
  backgroundColor: '#f0f0f0', // 添加背景色，与其他输入字段区分
  paddingHorizontal: 12, // 增加左右内边距
  borderRadius: 8, // 添加圆角
  paddingVertical: 6, // 增加上下内边距
},
selectArrow: {
  color: '#999',
  fontSize: 12,
  marginLeft: 8, // 增加文字和箭头之间的间距
},
```

### 保持账户类型可编辑

确认账户类型的 `editable` 属性已设为 `true`：

```typescript
{ label: '账户类型', value: '大陆客户', editable: true, key: 'accountType' },
```

## 修复后的效果

1. **布局改进**：账户类型选择框位于区块右侧，与其他输入字段对齐

2. **样式优化**：文字和箭头之间有适当的间距，选择框有背景色和圆角，外观更美观

3. **交互友好**：点击区域足够大，便于用户操作

4. **功能完整**：账户类型可以修改，修改后能正确保存

4. 保存修改，确认修改后的账户类型能正确保存
