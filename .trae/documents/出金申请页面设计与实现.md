# 出金申请页面设计与实现

## 设计目标
1. 创建功能完善的出金申请页面
2. 将首页的"出金申请"按钮链接到新的出金申请页面
3. 出金申请提交后写入数据库deposit_withdrawal表
4. 通知客服安排出金操作

## 实现方案

### 1. 创建出金申请页面

#### 页面功能
- 显示用户可用余额
- 输入出金金额
- 确认出金金额
- 提交出金申请
- 显示出金申请历史记录
- 支持中英文切换

#### 技术实现
- 创建新文件：`src/screens/WithdrawalApplicationScreen.tsx`
- 实现组件结构，包括头部、金额输入、历史记录等部分
- 添加表单验证逻辑
- 实现出金申请提交功能，写入deposit_withdrawal表
- 集成Supabase数据库操作

### 2. 修改App.tsx

#### 状态管理
- 添加新状态：`showWithdrawalApplication`
- 添加新状态：`showWithdrawalSuccess`
- 添加新状态：`withdrawalId`

#### 导航逻辑
- 在导航switch语句中添加`withdrawal-application`和`withdrawal-success`的处理
- 添加出金成功页面的条件渲染

### 3. 修改首页出金申请按钮

#### 跳转逻辑
- 将PortfolioScreen.tsx中的出金申请按钮跳转逻辑修改为：`onNavigateTo && onNavigateTo('withdrawal-application')`

### 4. 创建出金成功页面

#### 页面功能
- 显示出金申请成功信息
- 显示出金申请详情
- 提供返回首页和查看申请记录的选项

#### 技术实现
- 创建新文件：`src/screens/WithdrawalSuccessScreen.tsx`
- 实现成功页面的UI和交互

### 5. 数据库操作

#### deposit_withdrawal表操作
- 提交出金申请时，向deposit_withdrawal表插入新记录
- 记录字段：user_id, type='withdrawal', amount, status='pending', notes
- 查询用户的出金申请历史记录

#### 通知客服机制
- 在数据库操作成功后，添加控制台日志记录
- 后续可扩展为推送通知或邮件通知

## 页面结构

### WithdrawalApplicationScreen.tsx
```tsx
- 头部导航栏（返回按钮、标题）
- 可用余额显示
- 出金金额输入表单
  - 金额输入框
  - 确认金额输入框
  - 提交按钮
- 出金申请历史记录列表
```

### WithdrawalSuccessScreen.tsx
```tsx
- 成功状态显示（图标、文字）
- 出金申请详情
  - 申请ID
  - 出金金额
  - 申请时间
  - 状态
- 操作按钮（返回首页、查看记录）
```

## 数据模型

### 出金申请数据结构
```typescript
interface WithdrawalApplication {
  id: string;
  user_id: string;
  amount: number;
  status: 'pending' | 'approved' | 'processed' | 'completed' | 'failed' | 'cancelled';
  created_at: string;
  updated_at: string;
}
```

## 预期效果

- 用户点击首页"出金申请"按钮，跳转到出金申请页面
- 用户可以查看可用余额，输入出金金额
- 用户提交出金申请后，数据写入deposit_withdrawal表，显示出金成功页面
- 用户可以在出金申请页面查看历史记录
- 系统记录出金申请，通知客服安排出金操作
