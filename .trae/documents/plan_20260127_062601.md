# 将内参修改功能应用到admin和web平台的计划

## 一、Admin平台修改

### 1. 修改内参管理页面 (`internal-reference-management.tsx`)
- 添加公众号管理功能，包括创建、编辑、删除公众号
- 在文章列表中显示公众号信息
- 添加按公众号筛选文章的功能

### 2. 修改内参编辑器页面 (`internal-reference-editor.tsx`)
- 添加选择公众号的下拉菜单
- 添加封面图片URL输入字段
- 添加封面图片预览功能
- 在发布文章时关联到选定的公众号

### 3. 添加公众号管理页面
- 创建新的 `official-account-management.tsx` 页面
- 实现公众号的CRUD操作
- 显示公众号的文章数量和关注数

## 二、Web平台修改

### 1. 修改内参列表页面 (`insights/page.tsx`)
- 模仿微信公众号格式，顶部放置"常看"公众号区域
- 在文章卡片中显示公众号信息和封面图片
- 添加公众号详情页链接

### 2. 修改内参详情页面 (`insights/[insightId]/page.tsx`)
- 显示文章的封面图片
- 显示公众号信息和关注按钮
- 添加文章留言功能，支持回复
- 添加文章点赞功能

### 3. 添加公众号详情页面
- 创建新的 `insights/accounts/[accountId]/page.tsx` 页面
- 显示公众号信息、关注按钮和文章列表

### 4. 修改API路由
- 更新 `api/insights/route.ts`：支持按公众号筛选文章
- 更新 `api/insights/[insightId]/route.ts`：返回公众号信息和留言列表
- 添加 `api/accounts/route.ts`：处理公众号相关请求
- 添加 `api/comments/route.ts`：处理留言相关请求

3. 创建 `official-account-management.tsx` 页面，实现公众号管理功能

### 第二阶段：Web平台修改

2. 修改 `insights/[insightId]/page.tsx`，添加封面图片、公众号信息和留言功能

### 第三阶段：测试和优化
1. 测试三个平台的公众号功能

## 四、技术要点

### 1. 数据结构
- 复用已创建的数据库表结构：`wechat_official_accounts`、`account_follows`、`article_comments`
- 确保三个平台使用相同的数据模型

### 2. API设计
- 保持三个平台的API接口一致
- 使用相同的参数和返回格式

### 3. UI设计
- Admin平台：保持现有管理后台风格，添加公众号相关功能
- Web平台：模仿微信公众号格式，确保响应式设计
- 确保三个平台的用户体验一致

### 4. 功能同步
- 确保mobile平台的所有功能在admin和web平台都能使用
- 支持跨平台的数据同步和用户体验一致性
