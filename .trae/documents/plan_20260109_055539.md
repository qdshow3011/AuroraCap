### 我的资产页面设计计划

#### 1. 安装图表库
- **选择图表库**：使用 `react-native-chart-kit`，它与 Expo 兼容且易于使用
- **安装命令**：`npm install react-native-chart-kit react-native-svg`
- **兼容检查**：确保库版本与当前 React Native 和 Expo 版本兼容

#### 2. 创建新页面
- **文件路径**：`src/screens/AssetStatusScreen.tsx`
- **页面名称**：AssetStatusScreen（资产状况页面）
- **导航设置**：将新页面添加到应用导航中

#### 3. 页面布局设计

##### 顶部区域
- **保留资管模块的四个功能按钮**：
  - 入金服务
  - 出金申请
  - 资产状况（当前页面，高亮显示）
  - 成交状况
- **按钮样式**：与资管模块保持一致

##### 资产状况展示区

**文字说明部分**：
- 总资产显示
- 基金价值、现金余额、在途资金明细
- 资产变动趋势（如本月收益、年化收益率）

**饼状图部分**：
- 使用饼状图展示资产分布
- 图例说明各部分占比
- 图表下方显示各资产类别的具体数值和占比

##### 数据来源
- 复用 ProductsScreen 中的数据获取逻辑
- 从 Supabase 获取用户资产数据
- 数据结构与现有 MyAssets 接口保持一致

#### 4. 功能实现

**数据获取**：
- 复用 `loadData` 函数，获取用户资产数据
- 支持下拉刷新功能

**图表实现**：
- 使用 `PieChart` 组件创建饼状图
- 配置图表样式，确保美观清晰
- 处理数据格式转换，适应图表库要求

**交互设计**：
- 点击功能按钮跳转到对应页面
- 饼状图点击事件（可选）
- 数据加载状态处理

#### 5. 样式设计
- 保持与应用整体风格一致
- 使用现有样式变量和主题色
- 确保响应式设计，适配不同屏幕尺寸

#### 6. 测试与优化
- 测试数据加载和展示
- 优化图表性能
- 确保页面加载流畅
- 测试在不同设备上的显示效果

### 预期效果

- 清晰展示用户资产状况，既有文字说明又有直观的饼状图
- 保留了资管模块的核心功能入口
- 页面设计美观，交互流畅
- 提供了全面的资产信息，帮助用户了解自己的资产分布
