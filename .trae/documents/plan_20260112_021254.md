# 实现资讯中心消息管理功能

## 1. 需求分析

在admin的资讯中心增加一个子菜单——消息管理，用于管理系统产生的信息和公司公告等信息。

### 1.1 功能需求

* 消息不需要标题，直接体现消息内容

* 消息需要分类

* 公示对象选择（全体用户、合伙人、客户、服务员、管理员、登录用户）

* 实现消息未读和已读关系

* 提醒功能

* 创建时间

* 涉及到的用户（UUID）

* 产生人统一为系统生成

## 2. 技术方案

### 2.1 数据库设计

需要创建消息表和消息状态表：

#### 2.1.1 system\_messages表

```sql
CREATE TABLE IF NOT EXISTS system_messages(
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    content TEXT NOT NULL,
    category VARCHAR(50) NOT NULL,
    audience_type VARCHAR(50) NOT NULL,
    user_id UUID REFERENCES users(id) ON DELETE CASCADE,
    created_by VARCHAR(50) DEFAULT 'system',
    created_at TIMESTAMP WITH TIME ZONE DEFAULT NOW()
);
```

#### 2.1.2 system\_messages\_status表

```sql
CREATE TABLE IF NOT EXISTS system_messages_status(
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    message_id UUID REFERENCES messages(id) ON DELETE CASCADE,
    user_id UUID REFERENCES users(id) ON DELETE CASCADE,
    is_read BOOLEAN DEFAULT false,
    read_at TIMESTAMP WITH TIME ZONE,
    CONSTRAINT unique_message_user UNIQUE (message_id, user_id)
);
```
