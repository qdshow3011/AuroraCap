# 内参模块改造成公众号平台方案

## 一、数据库结构设计

### 1. 创建公众号表 (`wechat_official_accounts`)
- `id` (UUID): 主键
- `user_id` (UUID): 关联用户ID
- `name` (VARCHAR): 公众号名称
- `description` (TEXT): 公众号描述
- `avatar` (TEXT): 公众号头像URL
- `cover_image` (TEXT): 公众号封面图URL
- `status` (VARCHAR): 状态（active/inactive）
- `created_at` (TIMESTAMP): 创建时间
- `updated_at` (TIMESTAMP): 更新时间

### 2. 扩展文章表 (`internal_references`)
- 保留原有字段
- 添加 `account_id` (UUID): 关联公众号ID
- 添加 `cover_image` (TEXT): 文章封面图URL
- 添加 `read_count` (INTEGER): 阅读量
- 添加 `like_count` (INTEGER): 点赞数

### 3. 创建留言表 (`article_comments`)
- `id` (UUID): 主键
- `article_id` (UUID): 关联文章ID
- `user_id` (UUID): 留言用户ID
- `content` (TEXT): 留言内容
- `parent_id` (UUID): 父留言ID（用于回复功能）
- `status` (VARCHAR): 状态（approved/pending/spam）
- `created_at` (TIMESTAMP): 创建时间

### 4. 创建关注表 (`account_follows`)
- `id` (UUID): 主键
- `user_id` (UUID): 关注用户ID
- `account_id` (UUID): 被关注公众号ID
- `created_at` (TIMESTAMP): 关注时间

## 二、API设计

### 1. 公众号相关API
- `POST /api/accounts`: 创建公众号
- `GET /api/accounts`: 获取用户的公众号列表
- `GET /api/accounts/:id`: 获取公众号详情
- `PUT /api/accounts/:id`: 更新公众号信息
- `DELETE /api/accounts/:id`: 删除公众号
- `POST /api/accounts/:id/follow`: 关注公众号
- `DELETE /api/accounts/:id/follow`: 取消关注

### 2. 文章相关API
- `POST /api/articles`: 创建文章
- `GET /api/articles`: 获取文章列表（支持分页、排序、筛选）
- `GET /api/articles/:id`: 获取文章详情
- `PUT /api/articles/:id`: 更新文章
- `DELETE /api/articles/:id`: 删除文章
- `POST /api/articles/:id/like`: 点赞文章

### 3. 留言相关API
- `POST /api/articles/:id/comments`: 发表留言
- `GET /api/articles/:id/comments`: 获取文章留言列表
- `PUT /api/comments/:id`: 更新留言
- `DELETE /api/comments/:id`: 删除留言

## 三、前端页面设计

### 1. 公众号列表页（模仿微信公众号列表）
- 顶部放置"常看"公众号区域
- 下方显示关注的公众号列表
- 每个公众号显示头像、名称、最新文章标题和时间

### 2. 公众号详情页
- 显示公众号头像、名称、描述
- 下方显示文章列表，每个文章包含封面图、标题、摘要、阅读量、发布时间

### 3. 文章详情页
- 顶部显示文章标题、作者（公众号）、发布时间
- 中间显示封面图片
- 下方显示文章内容
- 底部显示阅读量、点赞按钮
- 留言区域：显示留言列表，支持发表留言和回复

### 4. 个人公众号管理页
- 显示用户创建的公众号列表
- 支持创建新公众号
- 支持编辑公众号信息
- 支持管理公众号的文章

### 5. 文章编辑页
- 支持标题、内容编辑
- 支持上传封面图片
- 支持选择发布到哪个公众号
