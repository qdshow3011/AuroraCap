# 聊天会话管理功能实现计划

## 1. 功能需求分析
- 聊天会话管理按客户名字列表展示
- 每个客户合并所有对话后只列一行
- 点击查看详情跳转到对话详情页面
- 详情页支持查看和删除具体对话

## 2. 数据模型设计

### 2.1 现有模型
- `ChatSession`：会话基本信息
- `Customer`：客户基本信息
- `Waiter`：服务员基本信息

### 2.2 新增模型
```typescript
// 对话消息类型定义
interface ChatMessage {
  id: string;
  session_id: string;
  sender_id: string;
  sender_type: 'customer' | 'waiter';
  content: string;
  created_at: string;
  deleted_at?: string;
}
```

## 3. 实现步骤

### 3.1 修改聊天会话管理标签页
- **文件**：`customer-service-management.tsx`
- **功能**：按客户合并会话，每个客户只显示一行
- **实现**：
  - 按客户ID对会话进行分组
  - 展示客户基本信息、最近会话状态、最后消息时间
  - 实现查看详情按钮，传递客户ID和会话ID

### 3.2 创建对话详情页面
- **文件**：`chat-detail.tsx`
- **功能**：显示客户和服务员之间的具体对话
- **实现**：
  - 页面布局：顶部客户信息，中间消息列表，底部操作按钮
  - 消息列表按时间顺序显示
  - 区分客户消息和服务员消息
  - 实现消息删除功能

### 3.3 实现消息数据获取
- **文件**：`customer-service-management.tsx` 和 `chat-detail.tsx`
- **功能**：从Supabase获取对话消息
- **实现**：
  - 添加`fetchChatMessages`函数
  - 支持按会话ID获取消息
  - 支持消息分页

### 3.4 实现消息删除功能
- **文件**：`chat-detail.tsx`
- **功能**：删除指定消息
- **实现**：
  - 添加`deleteChatMessage`函数
  - 实现删除确认模态框
  - 删除后更新消息列表

## 4. 技术实现要点

### 4.1 状态管理
- 使用React useState管理组件状态
- 使用React useEffect处理数据加载
- 支持消息列表实时更新

### 4.2 UI设计
- 使用Ant Design组件库
- 消息气泡设计：客户消息居左，服务员消息居右
- 支持消息时间显示
- 支持消息删除按钮

### 4.3 数据处理
- 会话分组：使用Map按客户ID分组会话
- 消息排序：按创建时间升序排列
- 数据缓存：避免重复请求
